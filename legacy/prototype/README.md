# Preserved hackathon prototype

Read-only reference, excluded from application and Docker runtime packaging. Secret scans still cover this directory.

`python.py` was the original prototype application; `data_fetch_argovis.ipynb` explored Argovis access and generated the scientific snapshot. The working notebook differed from committed history and was preserved as the current source input. Credential-shaped values were replaced with non-secret placeholders, and notebook outputs, execution counts, metadata and attachments were removed before archiving. These files are not executed by Stage 0.

`README.original.md`, the production architecture document and Draw.io diagram are sanitized reference copies, not the authoritative foundation specification.

The large Parquet file is not copied here. `tests/fixtures/profiles.parquet` is the bounded sample; its manifest records schema, checksum, sampling and attribution. Original dirty/untracked work and contaminated history were preserved separately in restricted non-synced storage. The original `Prototype/` directory is retained pending final owner-controlled disposition.
